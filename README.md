🛵 Sistema de gerenciamento de Biblioteca - Full Stack Project
Este é um Sistema Completo de Gerenciamento de Biblioteca desenvolvido para administrar o acervo, o cadastro de usuários e o fluxo de empréstimos e devoluções. O projeto foi estruturado para simular as operações essenciais de uma biblioteca moderna, focando na organização e controle de recursos.

O sistema permite o registro detalhado de livros, a gestão de membros e o controle de status de exemplares em tempo real.

🛠️ Tecnologias Utilizadas
Frontend
HTML, CSS e JavaScript: Para definição da estrutura das paginas, estilo e visual e implementação da logica de interaçao com o backend.
Backend
Node.js: Ambiente de execução JavaScript.
MySQL (mysql2): Banco de dados relacional.
NPM (Node Package Manager): Para gerenciar
dependências do backend, como Express, CORS, mysql2, nodemon e
outras.
Arquitetura MVC: Organização do código em Model, View e Controller.
Dotenv: Gerenciamento de variáveis de ambiente.
✨ Funcionalidades
✅ Gestão de Usuarios: Cadastro e listagem de usuarios.
✅ Gestão de Livros: Cadastro e listagem de Livros.
✅ Gestão de emprestimos: Registro e edição de emprestimo de livros.
✅ Gestão de multas: Registro e pagamento de multas para caso de atraso
✅ Controle de Status
